# 짐로그

%1RM 프로그램의 목표 무게를 자동으로 계산해 주는 운동 기록장입니다. 설치나 회원가입 없이 브라우저에서 바로 씁니다.

Claude나 다른 AI 계정이 없어도 모든 기록 기능(목표 무게 계산·기록·그래프·프로그램 만들기·백업)을 쓸 수 있습니다. AI 분석은 원할 때만 요약을 복사해 AI 채팅에 붙여 넣는 선택 기능입니다.

Claude를 쓰는 사람을 위한 버전(앱 안에서 바로 기록 분석·프로그램 변환)도 따로 있습니다. 링크는 이 페이지를 알려 준 사람에게 받으세요.

**주소:** https://deanehess.github.io/gymlog/

## 시작하기
1. 위 주소를 휴대폰 브라우저(크롬·사파리)로 엽니다.
2. **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.
   - 안드로이드 크롬: 오른쪽 위 ⋮ → "홈 화면에 추가" 또는 "앱 설치"
   - 아이폰 사파리: 아래(또는 주소창 옆) 공유 버튼 □↑ → 메뉴를 내려 "홈 화면에 추가" → 오른쪽 위 "추가". 안 보이면 메뉴 맨 아래 "작업 편집"에서 추가합니다. 아이폰에서 사파리 탭으로 열면 앱 첫 화면에 이 방법이 한 번 안내됩니다.
   - 아이폰은 **사파리 탭과 홈 화면 앱의 저장이 따로**입니다. 처음부터 홈 화면 앱으로만 쓰거나, 사파리에서 쓰던 기록은 백업 저장 → 홈 화면 앱에서 백업 불러오기로 옮기세요.
3. **설정 → 내 1RM · 목표**에서 벤치·스쿼트·데드·OHP 1RM을 입력합니다. 이 값으로 프로그램 목표 무게가 계산됩니다.
4. 예시 프로그램(거인화 v3.0 · 6주 4분할)을 그대로 쓰거나, **설정 → 운동 프로그램**의 **프로그램 직접 만들기**로 내 프로그램을 만듭니다.

## 기록은 내 기기에만 저장됩니다
- 아이폰에서 받은 백업·샘플 파일은 **파일 앱 → 다운로드** 폴더에 저장됩니다. 불러올 때도 거기서 고르세요.
- 기록은 이 기기의 브라우저에만 저장되고 서버로 보내지 않습니다. 다른 사람은 볼 수 없습니다.
- 그래서 **브라우저 데이터를 지우거나, 휴대폰을 바꾸거나, 다른 브라우저로 열면 기록이 보이지 않습니다.**
- **설정 → 백업 · 불러오기**의 **JSON 백업 저장**으로 가끔 파일을 저장해 두세요. 새 기기에서는 **백업 불러오기**로 그대로 옮길 수 있습니다.
- 인터넷이 없어도 한 번 열어 본 뒤에는 사용할 수 있습니다(엑셀 가져오기는 인터넷 필요).

## 내 프로그램 넣기 (프로그램 불러오는 법)
먼저 **설정 → 내 1RM · 목표에서 1RM을 입력**하세요. 아래 버튼은 모두 **설정 → 운동 프로그램**에 있습니다. 프로그램 무게는 "프로그램에 적힌 % × 내 1RM"으로 계산됩니다.

1. **샘플 양식대로 된 엑셀·CSV**: **엑셀·CSV 프로그램 가져오기**로 바로 올립니다. 6주_4분할 v3.0처럼 %1RM 수식이 든 엑셀도 그대로 읽습니다.
2. **인터넷에서 받은 아무 양식의 엑셀**: **샘플 양식 받기**와 **AI에 줄 문구 복사**를 누른 뒤, claude.ai(무료도 됨) 새 채팅에 원래 파일·샘플 양식·복사한 문구를 같이 올립니다. Claude가 준 엑셀을 1번처럼 가져옵니다.
3. **자유 운동 → 프로그램으로 저장**: 프로그램 없는 날 자유 운동을 하고 "운동 마치기"를 누르면 나오는 **프로그램으로 저장**에서 프로그램(새로 만들기 또는 기존)과 Day 1~7, 적용 주차를 고릅니다.
4. 가져온 뒤 **이 프로그램 사용**을 누르고 **시작일**을 1주차 첫 운동일로 맞춥니다. 틀린 곳은 프로그램 목록의 **편집**에서 고칩니다.

알아 둘 점
- Day는 시작일부터 하루씩 이어집니다(월=Day 1, 화=Day 2 …). 월·수·금처럼 쉬는 날이 끼는 프로그램은 오늘 탭 **프로그램·주차·Day 변경**에서 그날 할 Day를 고르세요.
- 1RM을 넣으면 무게가 계산되는 엑셀은 계산된 결과(만든 사람 1RM 기준)만 읽힙니다. % 칸이 없으면 AI가 내 1RM으로 다시 나눠 %로 바꿉니다.
- 트레이닝 맥스(TM) 프로그램은 1RM 칸에 TM을 넣고 쓰세요. RPE로만 정한 종목은 무게 없이 세트×반복으로 들어옵니다.

## 인바디 불러오기
인바디 앱에서 측정 기록을 CSV(또는 엑셀)로 내보낸 뒤, **프로필 탭 → 인바디 불러오기**에서 파일을 고르면 날짜·체중·골격근량·체지방량·체지방률·내장지방·기초대사량이 들어갑니다. 이미 있는 날짜는 건너뜁니다.

## AI로 기록 분석받기
**프로필 탭 → Claude로 기록 분석**에서 기간(4·8·12주·전체)을 고르고 **요약 복사**를 누른 뒤 claude.ai(무료 계정도 됨) 새 채팅에 붙여 넣으면 종목별 추이, 정체 구간, 볼륨 균형, 다음 4주 조언을 받을 수 있습니다. 기록은 복사할 때만 기기 밖으로 나갑니다. 더 자세히 보고 싶으면 설정 탭의 JSON 백업 파일을 통째로 올려도 됩니다.

## 주요 기능
- 주차·요일에 맞춰 오늘 할 운동과 목표 무게·반복 수 표시, 원판 조합 안내
- **한 번에 운동 하나**: 오늘 탭은 지금 할 운동만 크게 보여 줍니다. 세트마다 ✓, 다 하면 **다음 운동 →**. 번호 동그라미나 **전체 보기**로 다른 운동으로 이동합니다. 세트 추가·운동 교체·메모·슈퍼세트·삭제는 운동 오른쪽 위 **⋮** 안에 있습니다. 예전처럼 한 화면에 모두 보려면 설정 → 화면 설정.
- 설정 탭은 메뉴(내 1RM · 목표 / 운동 프로그램 / 내 종목 / 백업 · 불러오기 / 사용법 / 화면 설정)에서 하나씩 들어갑니다.
- 세트별 무게·반복·RIR 기록, 휴식 타이머, 세트 종류(웜업·드롭·실패), PR 알림
- 운동 교체·메모·슈퍼세트, 자유 운동 기록
- **새 종목 만들기**: 종목마다 운동 도구·근육 부위·기록 단위(무게×횟수, 횟수, 시간, 시간×거리)를 정함. 이름 → 도구 → 부위 → 보조 부위 → 단위 순서로 하나씩 고릅니다. ⋮ → 운동 교체 창이나 설정 → 내 종목에서. 플랭크는 시간, 러닝은 분·km로 기록
- 기록 탭, 몸 기록(체중·허리·체지방·골격근), 종목별 볼륨·e1RM 차트(기간 선택, 밀어서 이동, 확대)
- 샘플 양식·CSV·%1RM 수식 엑셀 프로그램 가져오기, 프로그램 직접 만들기, 자유 운동을 프로그램으로 저장
